BEFORE GOING LIVE:

1. Change admin password in .env.local:
   ADMIN_PASSWORD=YourNewSecurePassword123

2. Add your real product images:
   - Place JPG/PNG files in public/products/
   - Select them when adding products from admin dashboard

3. Update WhatsApp number in lib/format.ts:
   - WHATSAPP_NUMBER = "966" + your number
   - WHATSAPP_DISPLAY = "05" + your number

4. Enable real payment (optional now, required for live):
   - Sign up at https://moyasar.com (Saudi-licensed)
   - Get API keys
   - Add to .env.local:
     MOYASAR_PUBLISHABLE_KEY=pk_live_xxxxx
     MOYASAR_SECRET_KEY=sk_live_xxxxx
   - Code ready for integration in app/api/pay/route.ts

5. Add .env.local to .gitignore before pushing to Git

  lib/format.ts            → Constants (prices, statuses, payment methods)

  data/store.db            → SQLite database with all orders/products

================================================================================
                          DEPLOYMENT QUICK GUIDE
================================================================================

Vercel (recommended):
  1. git add . && git commit -m "ready for production"
  2. git push origin main
  3. Vercel deploys automatically

Self-hosted:
  1. npm run build
  2. npm run start
  3. Set NODE_ENV=production
  4. Ensure data/ directory is writable

Database:
  - Currently SQLite (data/store.db)
  - For scale: migrate to PostgreSQL/MySQL
  - Connection string goes in .env.local

================================================================================
                            ADMIN DASHBOARD TABS
================================================================================

Tab 1: Custom Designs
  - Shows all /custom requests waiting for your review
  - Download customer's file (STL, image, etc.)
  - Enter price and approve OR enter reason and reject
  - After customer pays, manage print status (start print → shipped → delivered)

Tab 2: Orders
  - Shows all /products purchases
  - Dropdown to change status: pending_payment → paid → processing → shipped → delivered
  - Instant status sync to customer's /track page

Tab 3: Products
  - Add new: name, description, price, category, image, stock
  - Edit existing
  - Hide/show (soft delete, preserves order history)
  - Left side: form | Right side: product grid
